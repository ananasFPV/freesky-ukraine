# Free Sky Ukraine

Сайт школи FPV-дронів і STEM для дітей. Статичний: HTML + CSS + JS, без збірки й залежностей.

## Запуск локально

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Структура

- `index.html` — усі вкладки сайту (`<section class="view" data-view="...">`)
- `css/style.css` — стилі, кольори в `:root`
- `js/app.js` — перемикання вкладок з анімацією, меню, перемикач мови, форма запису
- `js/i18n.js` — англійський переклад (ключі — атрибути `data-i18n` в `index.html`)
- `img/` — логотип і фото

Вкладки відкриваються за адресою `#/назва`: `#/about`, `#/courses`, `#/trial`, `#/races`, `#/team`, `#/faq`, `#/partners`, `#/contacts`, `#/sponsors`.

## Мови

Український текст пишеться прямо в `index.html`. Для англійської в `js/i18n.js` лежить переклад за тим самим ключем `data-i18n`. Якщо змінюєте текст українською, оновіть і англійський рядок.

## Як вставити фото

Кожне вікно під фото — це `.frame__slot`. Додайте всередину `<img>`:

```html
<div class="frame__slot" data-label="IMG 01">
  <img src="img/table.webp" alt="Стіл з дронами й пультами" loading="lazy">
</div>
```

Фото краще стискати у WebP до ~1600 px по довшій стороні.
Обличчя дітей — лише на фото зі змагань.

## Що ще треба уточнити

Усе, що позначено на сайті жовтою рамкою «уточнити»: адреси, точна ціна, курси 3D-друку й ШІ,
кількість учнів, імена/фото інструкторів, посилання на соцмережі, нік у TikTok, дата наступних змагань.

Заявки з форми йдуть у Google-таблицю й Telegram через Google Apps Script — інструкція в `apps-script/README.md`.
Поки `FORM_ENDPOINT` у `js/app.js` порожній, форма відкриває WhatsApp менеджера.
