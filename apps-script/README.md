# Заявки з сайту → Telegram + Google-таблиця

Налаштування займає близько 10 хвилин, нічого платити не треба.
Після цього кожна заявка з форми «Запис на пробне»:

- з'являється новим рядком у Google-таблиці;
- приходить повідомленням у Telegram менеджеру або в робочий чат.

## 1. Створити бота в Telegram

1. Відкрийте [@BotFather](https://t.me/BotFather) і надішліть `/newbot`.
2. Придумайте назву (наприклад, `Free Sky заявки`) та юзернейм, що закінчується на `bot`.
3. BotFather надішле **токен**, схожий на `7712345678:AAH...`. Скопіюйте його й нікому не показуйте.
4. Напишіть своєму новому боту `/start` з того акаунта, куди мають приходити заявки.
   Якщо хочете отримувати заявки в груповий чат, додайте бота в цю групу й напишіть там будь-що.

## 2. Створити таблицю і скрипт

1. Створіть нову Google-таблицю, наприклад «Free Sky — заявки».
2. У меню таблиці: **Розширення → Apps Script**.
3. Видаліть усе у файлі `Code.gs` і вставте вміст файлу [`Code.gs`](Code.gs) з цієї папки. Натисніть 💾.

## 3. Вписати токен і знайти CHAT_ID

1. Ліворуч натисніть ⚙️ **Налаштування проєкту** → внизу **Властивості скрипта** → **Додати властивість**.
2. Додайте `BOT_TOKEN` зі значенням токена з кроку 1. Збережіть.
3. Поверніться до редактора, у списку функцій угорі виберіть `findChatId` і натисніть **Виконати**.
   Google попросить доступ: **Переглянути дозволи** → виберіть акаунт → **Додатково** → **Перейти до проєкту** → **Дозволити**.
4. Унизу в журналі з'явиться рядок `CHAT_ID: 123456789`. Для групи номер буде з мінусом, наприклад `-1001234567890`.
5. Додайте ще одну властивість `CHAT_ID` з цим номером.
6. Перевірка: виберіть функцію `testSubmit` і натисніть **Виконати**. У таблиці з'явиться аркуш «Заявки» з тестовим рядком, а в Telegram прийде повідомлення.

## 4. Опублікувати як веб-застосунок

1. Угорі праворуч: **Розгорнути → Нове розгортання**.
2. Біля «Виберіть тип» натисніть ⚙️ → **Веб-застосунок**.
3. Виконувати як: **Я**. Хто має доступ: **Усі**.
4. **Розгорнути**. Скопіюйте **URL веб-застосунку**: він закінчується на `/exec`.

## 5. Підключити сайт

Надішліть цей URL розробнику сайту, або вставте його самі в `js/app.js` на початку файлу:

```js
var FORM_ENDPOINT = 'https://script.google.com/macros/s/.../exec';
```

Поки рядок порожній, форма працює як раніше і відкриває WhatsApp менеджера.
Якщо скрипт колись не відповість, сайт покаже батькам посилання на WhatsApp, тож заявка не загубиться.

## Якщо змінюєте скрипт

Після будь-яких змін у `Code.gs` треба зробити **Розгорнути → Керувати розгортаннями → ✏️ → Версія: Нова версія → Розгорнути**.
URL при цьому лишається той самий.
