# Тестова копія сайту

Адреса: https://ananasfpv.github.io/freesky-ukraine/test/

Окрема копія для перевірки змін. Основний сайт (корінь репозиторію) вона не зачіпає.
Сторінка закрита від пошукових систем (`noindex`), у шапці помітка «ТЕСТ».

Що тут нового — розділ «Оренда траси» (`#/rent`) і дрібні покращення, список у звіті в проєкті.

## Заявки на оренду

Форма оренди шле заявку на ту саму адресу Apps Script, що й форма пробного (`FORM_ENDPOINT` у `js/app.js`),
з полем `type=rental`.

- Поки скрипт у Google не оновлено, заявка все одно приходить у той самий Telegram
  як «Нова заявка на пробне», але в полі «Ім'я» буде «ОРЕНДА ТРАСИ · ім'я · дата, години, пілоти».
- Після оновлення скрипта (`apps-script/Code.gs` у цій папці) приходить окреме повідомлення
  «🏁 Заявка на ОРЕНДУ ТРАСИ» з усіма полями, а в таблиці з'являється аркуш «Оренда траси».

Як оновити скрипт: відкрити проєкт Apps Script → замінити код вмістом `apps-script/Code.gs` → Зберегти →
Розгорнути → Керувати розгортаннями → олівець → Версія: «Нова версія» → Розгорнути.
Адреса веб-застосунку не зміниться, форма пробного працює як раніше.
